설명

0~99 사이 두 수로 덧셈이나 뺄셈 문제를 20개 냅니다.
맞으면 "Ok", 틀리면 정답을 보여 주고 마지막에 맞힌 개수를 찍습니다.
곱셈 20문제는 이 파일을 고쳐 만들었습니다.

소스

CLSRANDOMIZE TIMERFOR i = 1 TO 20a = INT(RND * 100)b = INT(RND * 100)d = INT(RND * 2)IF d = 0 THEN PRINT a; "+"; b; "="; ca = a + bEND IFIF d = 1 THEN PRINT a; "-"; b; "="; ca = a - bEND IFINPUT cIF c = ca THENPRINT "Ok"s = s + 1END IFIF ca <> c THEN PRINT "no,correct answer is "; caNEXT iPRINT "Total Correct answer is "; s

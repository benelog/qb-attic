설명

DON2.WAV의 크기를 LOF로 읽어 INTEGER 변수에 넣는 일곱 줄짜리 시험입니다.
파일 이름(OVERLF)으로 보아 32767바이트가 넘는 길이가 정수에서 넘치는지(overflow) 본 것 같습니다.
청기백기의 RUNDMA는 길이를 LENG&(LONG)로 받습니다.

소스

 DIM lf AS INTEGER f$ = "c:\flag\don2.wav" OPEN f$ FOR RANDOM AS #1 LEN = 200 FIELD 1, 200 AS R$ PRINT LOF(1) lf = LOF(1) CLOSE

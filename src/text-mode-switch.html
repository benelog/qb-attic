설명

SCREEN 0, 0, 0으로 텍스트 화면으로 돌아가 "Graphic Mode ----> Text Mode"를 찍고 키를 기다립니다.
같은 폴더에 TS.EXE가 있습니다.
그래픽 프로그램이 비정상으로 끝나 화면이 그래픽 모드에 남았을 때 쓰려던 것으로 보입니다.
"made by Sang-Hyuk", "Pc-Serve ID: Bobble"이라는 서명이 있습니다.

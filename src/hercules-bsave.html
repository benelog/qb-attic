허큘리스 화면 BSAVE 시험

hercules-bsave.bas

원래 파일
LAN/QB/BSAVE.BAS
날짜
1991-10-08
크기
479바이트, 7줄
저장 형식
QB 4.5 바이너리 저장본("Fast Load and Save")을 QB에서 텍스트로 다시 저장한 뒤 UTF-8로 바꿈
내려받기
hercules-bsave.bas (UTF-8)

설명

SCREEN 3에 선과 원을 그린 뒤 DEF SEG = &HB000, BSAVE "ae", 0, &H8000으로 화면 메모리를 통째로 저장합니다.
그림판의 SBSAVE가 같은 방법을 씁니다.

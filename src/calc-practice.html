설명

+ 12 - 5 + 7 같은 여러 항의 덧셈·뺄셈 문제를 내는 암산 연습기입니다.
항 개수, 자릿수, 문제 수, 문제당 시간을 차례로 입력받습니다.

  • 끝나면 맞힌 개수와 백분율을 보여 주고 CLEAR 뒤 처음부터 다시 합니다.
  • 문제당 시간을 입력받지만 코드는 그 값을 쓰지 않습니다.
  • "your correc answer is" 같은 오타도 원문 그대로입니다.

덧셈·뺄셈 20문제를 일반화한 판입니다.

소스

CLSPRINT "                   ****** Calculation Practice Trainer *****"PRINTPRINT "                                          Programmed by Jung-Sang-Hyuk"PRINT "                                                Version 1.0"DORANDOMIZE TIMERINPUT "XX+XX+XX ...", hsINPUT "XXXX........", jsINPUT "How many problems do you want to solve?", mhINPUT "How long do you take to solve a problem?", tmDIM pb(hs), cas(mh), mj$(mh)FOR j = 1 TO mh FOR i = 1 TO hs pb(i) = INT(RND * 10 ^ js) bh = INT(RND * 2) IF bh = 0 THEN  b$ = "+"  cas(j) = cas(j) + pb(i) END IF IF bh = 1 THEN  b$ = "-"  cas(j) = cas(j) - pb(i) END IF mj$(j) = mj$(j) + " " + b$ + STR$(pb(i)) NEXT i NEXT j FOR i = 1 TO mh PRINT mj$(i); "  "; INPUT A IF A = cas(i) THEN PRINT "OK" cr = cr + 1 ELSE PRINT "no, correct answer is"; cas(i) END IF NEXT i PRINT "your correc answer is"; cr; "of"; mh; "problems" PRINT cr / mh * 100; "%" PRINT "Press Any Key..." WHILE INKEY$ = "" WEND CLEAR LOOP
